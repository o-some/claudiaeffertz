## Vor der offiziellen Domainaufschaltung

- Rechtssichere Angaben für Impressum und Datenschutz ergänzen
- Gewünschte E-Mail-Adresse oder Formularanbieter bestätigen
- `noindex, nofollow` aus `index.html` entfernen
- DNS der Produktionsdomain auf GitHub Pages umstellen und die Domain in GitHub bestätigen

GitHub bleibt die einzige Quelle für weitere Änderungen und Veröffentlichungen.
